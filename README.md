## Tema Bisnis
Layanan Kurir Pengiriman Cepat dan Titip Beli Area Kampus.

## Deskripsi Website
SATSET merupakan layanan kurir area kampus yang menyediakan jasa pengiriman dokumen, titip beli makanan, dan angkut barang kost. Website ini dilengkapi katalog layanan dan kalkulator untuk menghitung estimasi biaya berdasarkan jenis layanan dan jarak pengiriman.

## Layanan SATSET
1. **SATSET DOCS** — Paket Pengiriman Dokumen.
2. **SATSET JAJAN** — Paket Titip Beli Makanan.
3. **SATSET ANGKUT** — Paket Angkut Barang Kost.

## Fitur Website
- Informasi dan katalog tiga layanan SATSET.
- Kalkulator estimasi biaya berdasarkan harga layanan per kilometer dan jarak pengiriman.
- Kode promo `SATSET10` untuk diskon 10%.
- Tampilan responsif untuk komputer dan ponsel.
